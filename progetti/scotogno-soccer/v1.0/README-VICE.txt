This page runs SCOTOGNO SOCCER in VICE.js, a JavaScript port of VICE 2.4
(the Versatile Commodore Emulator), made with Emscripten by R. Janicek.

VICE and VICE.js are free software, released under the GNU General Public
License version 2 (see LICENSE-VICE.txt). x64.js is distributed unmodified.
Source code: https://github.com/rjanicek/vice.js  (VICE: https://vice-emu.sourceforge.io/)

The game file (soccer.prg) is not part of VICE.
vicerc only sets the keyboard joysticks: PL1 (port 2) arrows + space,
PL2 (port 1) W A S D + left shift.
